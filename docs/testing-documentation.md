# Testing documentation

## Purpose

Use this file to record the test plan and actual results. No testing has been performed or claimed by this starter document.

## Test environments

Record browser and version, operating system, viewport sizes, assistive technologies, test date, and tester for each run.

## Suggested checks

- Validate every HTML page and confirm each relative CSS, JavaScript, image, and navigation link.
- Parse both JSON data files and verify required fields, unique IDs, types, and units.
- Check calculator input validation, zero values, quantity, daily totals, the 30-day monthly estimate, and tariff/currency handling once agreed.
- Check appliance search, category filtering, sorting, loading errors, and empty results.
- Check keyboard-only use, focus visibility, labels, accessible names, contrast, and reduced motion.
- Check layouts at mobile, tablet, and desktop viewport widths.
- Test static hosting under a project subpath, as used by GitHub Pages.
